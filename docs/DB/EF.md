EDM "Entity Data Model" -> the total sum of your entities, their properties, and their relationships.

When you create a migration, you get back three files...
`foo.cs` -> the migration definition file that you're allowed to edit (no autogenerated tag)
`foo.Designer.cs` -> metadata storing a snapshot of the model (EDM) at the time you created the migration
`Snapshot.cs` this is used to decide what needs to change in the next migration (not the next update)

`#pragma warning disable 612, 618`
Disables warnings for "Obsolete" or "Deprecated" code.
EF uses these pragmas because generated code often uses older APIs for backward compatibility
`#pragma warning restore 612, 618`

A "navigation property" is a class property that lets EF 'navigate' between relational tables (to create JOINs).

You don't need dotnet-ef (CLI tool for developers) for `db.Database.MigrateAsync()` (uses stdlib).
